# 🎫 Visit App

تطبيق ويب عربي لتنظيم وتجهيز الزيارات والاجتماعات بطريقة بسيطة وسريعة.

## ✨ المميزات

- واجهة مستخدم عربية.
- تكامل مع Firebase.
- المصادقة المجهولة (Anonymous Authentication).
- تخزين البيانات باستخدام Firestore.
- دعم العمل دون اتصال عند توفره في إعدادات التطبيق.
- مزامنة البيانات في الوقت الفعلي عند الاتصال.
- دعم PWA إذا كان إصدار التطبيق المنشور مفعّلاً بهذه الميزة.

## 🌐 التطبيق

[فتح Visit App](https://visit-app-mama.web.app)

## 🚀 الاستخدام

1. افتح التطبيق.
2. اختر **إضافة زيارة**.
3. أدخل بيانات الزيارة.
4. احفظ البيانات.
5. راجع الزيارات المسجلة.

## 🛠️ التطوير

المستودع الحالي يحتوي على حزمة التطبيق الجاهزة. قبل تنفيذ تعديلات برمجية، يُفضّل توفير شجرة المصدر البرمجية الكاملة للمشروع حتى يمكن بناء واختبار التغييرات بشكل موثوق.

المتطلبات المتوقعة لأي نسخة Node/Firebase من المشروع يجب اعتمادها من ملفات المشروع الفعلية قبل تثبيت أرقام إصدارات محددة.
