# تطبيق تجهيز الزيارة (PWA)

تطبيق على موبايلك وموبايل ماما، من غير Claude ومن غير تسجيل دخول.
الداتا في Firebase (Firestore) على حسابك أنت. الخطة المجانية كافية.

## 1) إنشاء مشروع Firebase (مرة واحدة)
1. افتح https://console.firebase.google.com واعمل Project جديد (ممكن تقفل Google Analytics).
2. من Build > **Authentication** > Get started > Sign-in method > فعّل **Anonymous**.
3. من Build > **Firestore Database** > Create database (اختار أقرب منطقة، Production mode).
4. من Project settings (⚙) > Your apps > اضغط `</>` (Web) وسجّل التطبيق.
   انسخ كائن `firebaseConfig` والصقه في `public/config.js` مكان القيم `PASTE_...`.

## 2) النشر
```bash
npm install -g firebase-tools
firebase login
firebase use --add            # اختار المشروع
firebase deploy --only hosting,firestore:rules
```
بعد النشر هيطلعلك رابط شكله `https://اسم-مشروعك.web.app`.

## 3) الاستخدام
1. افتح الرابط على موبايلك (Chrome على أندرويد، أو Safari على آيفون).
2. اضغط **ابدأ مساحة جديدة**.
3. انزل لكارت **المشاركة والتطبيق** واضغط **ابعت لماما على واتساب**.
4. ماما تفتح الرابط من واتساب:
   - **أندرويد:** من Chrome → القايمة ⋮ → تثبيت التطبيق.
   - **آيفون:** من Safari → مشاركة □↑ → إضافة إلى الشاشة الرئيسية.
5. ثبّت التطبيق عندك إنت كمان بنفس الطريقة.

الرابط فيه كود سري طويل (بعد علامة `#`) وهو اللي بيدخل المساحة. أي حد معاه الرابط يقدر يعدل، فبلاش تنشره.

## 4) نقل الداتا من صفحة Claude
في صفحة Claude: **نسخة احتياطية** وهتنزل ملف. في التطبيق الجديد: **استرجاع نسخة** واختار الملف.
الاسترجاع بيضيف الناقص بس ومبيمسحش حاجة. (صور صفحة Claude مش بتنتقل، صوّرها تاني من ⚙ على الحاجة.)

## ملاحظات
- يشتغل أوفلاين: التعديلات بتتبعت لما النت يرجع.
- الصور بتتصغّر (320px) وبتتخزن جوه Firestore نفسه، فمش محتاج Firebase Storage. (يفضّل JPG/PNG؛ صور HEIC من الآيفون ممكن متشتغلش)
- **التثبيت على كل الأجهزة:**
  - **أندرويد (Chrome):** زر «ثبّت التطبيق» أو القايمة ⋮ ← تثبيت التطبيق.
  - **آيفون (Safari):** زر المشاركة □↑ ← «إضافة إلى الشاشة الرئيسية».
  - **الكمبيوتر:** من شريط العنوان أيقونة التثبيت (إن وُجدت).
- لتحديث التطبيق بعد أي تعديل: غيّر `VERSION` في `public/sw.js` وأعد `firebase deploy`.
- لو ظهرت رسالة خطأ، أول حاجة افحصها: Anonymous Auth متفعّل، والقواعد اتنشرت، وconfig.js صح.
